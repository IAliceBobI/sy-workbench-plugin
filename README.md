# 工作台

**晚上 AI 备好明天的弹药，白天你自己打，晚上对账补弹——不用记录，计划即账本。** 全部功能免费。

## 这是什么

把你的项目、任务、日程、提醒收进一个工作台，让 AI 每天替你把明天安排好。

计划为什么总是执行不下去？因为计划写完的那一刻就开始过期，白天一忙起来，就没有人再管它了。工作台的做法是把「安排明天」变成每晚三分钟的小事：AI 替你准备好，你点头，明天照着过；走过的路自动成为账本，不用打卡、不用补记。

你的问题往往不是任务太多，是十件事没有一条统一的时间线。

## 一天三拍

- **晚备弹** — 交接会，三分钟。AI 读三样东西：你今天手写的感想、实际怎么过的账、每个项目的近况。先对账（配额 vs 实际、不想做清单的镜子），再讨论（白天冒出的念头、要不要拆树挪枝），你点头后 AI 落三件套：项目增量、明天的弹药（任务+配额）、明天的锚点。
- **白天打** — 时间线常驻手边。锚点（接送、开会这类时刻硬的安排）是硬块；弹性任务没有时刻，只有配额——在弹药库面板点「开始/停止」打点，开始新的会自动闭合上一个，账本只记真实发生的事。番茄钟长在时间线上，用不用随你——它是节奏器，不是记账器。走过的路自然留痕，**计划即账本**。
- **晚对账** — AI 拿证据说话：✅ 有证据完成、❌ 有证据未完成、❓ 无证据才问你。每周日一份「照镜子」周报，对照基线看这周过得怎么样。某天没开会也没关系，不追责、不补债，明天接着打。

**每天晚上三分钟：AI 报账，你点头，明天的弹药就装好了。**

## 弹药库：今天的任务装在四个池子里

四个性格不同的池子，各有各的配额性格：

| 池 | 装什么 | 配额性格 |
|---|---|---|
| 黄金产出 | 人生目标细拆出来的事 | **保底配额**——被挤掉时交接会替你抗议 |
| 当日死线 | 今天必须交付的硬事 | 就事论事，完成即销 |
| 维持炉火 | 不紧急但不能一直拖的事（维护、跟进反馈） | **上限配额+最小频率**——超了提醒，凉了也提醒 |
| 碎片杂项 | 回消息、杂务、临时小事 | 不保底不设限，但记账 |

两级软配额：晚上和 AI 讨论定，白天照实扣。用完显示「已消耗」，继续用显示「多用 X 分钟」，**全程不拦截**——配额是仪表盘，不是栅栏。

## 不想做清单

不想做，比想做更有动力。中央圈收三类：

- **戒条**（不想熬夜刷手机）——无数据，晚间一问，答了记账不追问；
- **怕来不及**（怕想学的技能一直拖着没学）——想要的负面面具，AI 翻译成正面任务进池；
- **防沉迷**（不想过度打游戏）——直接物化成对应池子的时间上限。

它是配额的民意基础。核心机制只有一条：**AI 只递镜子，不做法官**——超限时它引用的是你自己的原话（「你说过不想天天加班，今天又加了 2 小时，这是本周第二次」），评判力度全部来自你自己，AI 从不产生新指责。

## 项目树与日账

两个本体，界面全是投影：

- **项目树=想要的世界**。一个大目标一篇项目文档：任务、里程碑、纯目标都写在里面。甘特图给每个项目一条泳道：任务是横条，里程碑是菱形，完成的、进行中的、过期的各有形态；别处引用它的地方结成果点；「现在」是一条红线横穿全图；长间隔断轴压缩（「断 N 天」诚实标记），长线项目一屏看全；「回到现在」一键复锚。**看的不只是清单，是时间轨迹。**
- **日账=发生的世界**。`/Project/日志/` 按月一篇、按日分组：锚点和打点自动写入当天那节，睡觉不碰就是空白。手写感想归官方日记，不混。

项目树就是你的方向感：**有梦想的照着走，没梦想的长出来。** 不搞一夜翻身，一步最多朝目标挪 30 分钟，每天进步一点。

## 价值观

这个插件信渐进：不追求一夜蜕变，追求明天的弹药比今天靠谱一点。

每天的执行是**收据，不是考卷**。不评分、不追责、不做爆红的拖延数值——惩罚不产生行动，参照才产生行动。

不是计划没用，是愿望式计划没用。好计划的三个要件——具体的行动安排、从你的真实历史出发的容量估算、留缓冲——这个插件让 AI 替你全包了。

## 功能速览

### 核心模型：块是唯一事实源
- 所有项目住在同一个目录（默认 `Project`，可随意改名）里：**一个项目就是目录下的一篇文档**，任务直接写在项目文档里——思源原生任务列表块，勾一个是一个；子文档随意嵌套，嵌套里的任务也算这个项目的。不另建数据库——**块和 custom-* 属性是唯一事实源**，搬走、同步、备份都跟你的笔记一体。
- 内核 MCP 大脑（kernel.js，思源内核侧常驻）+ 前端薄壳。

### 项目与现场恢复
- 顶栏切换器：项目间一键切换，一键打开驾驶舱。
- 现场保存/恢复：保存页签集快照，切回项目即恢复原现场；「恢复现场」按钮一键回到上次快照，丢弃当前散乱现场。

### 驾驶舱
- 项目文档、子文档平铺入口、全局日志（当月一篇）一览；甘特泳道视图按时间轴看每个项目的进度。
- 子文档整理交给 AI：拆分、合并、归档、找回（blocks / split / merge / archive / restore），块 id 全程保留，双链不断。

### 弹药库与看板
- 四池面板+不想做清单：常驻悬浮窗（默认 ⌥⇧⌘A）随时看、随手点开始/停止；dock 里也有。
- 看板视图：按池或按项目两种分栏看任务。

### 当天时间线与班表
- 时间线常驻，滚轮翻动；锚点排班表，可镜像到外部日历。
- 拖动条目改时间，AI 会在交接会上顺口问「以后都这样排吗」。

### 番茄钟
- 长在时间线上，点开始按节奏循环；与「番茄工具箱」可共存，两边同时计时只提醒一次，不硬拦。

### 提醒与飞书日历
- 块级定时提醒：单次、每天、每周、每月、每隔 N 天、按星期。
- 飞书日历双向同步，配置走 AI 引导——设置面板里复制一句话发给 AI 助手即可完成授权；授权失效有红态提醒，一键重授权。

### 动作按钮
- 项目文档 `## 动作` 段写清单（`- 名称 | 命令`），自动渲染成按钮；白名单命令（`code` / `open` / `mpv` / `play`）直接跑，其余点按时亮出全文再执行。

### MCP 工具族
- AI 助手（ZCode / Cursor 等）通过内核 MCP 直接查询与操作项目、子文档、任务、日历、提醒、作息、弹药库——对话即操作。

## 凭什么信你

- **推送无遗漏**：锚点和带截止的任务自动写飞书日程，到点由飞书服务端推送——思源关着也能到，换设备也能到。
- **双向同步**：两边互写。在飞书日历里拖时间、改标题、删事件，自动回写班表，两本日历保持一致——**拖动本身就是学习信号**，AI 看得懂你在把生活往哪边挪。
- 思源开着时每小时自动补一轮同步；白天的实况打点也可一键同步成日历回填。
