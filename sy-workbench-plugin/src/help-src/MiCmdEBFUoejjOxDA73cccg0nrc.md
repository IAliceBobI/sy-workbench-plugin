驾驶舱是打开一个项目时的总控台：进度、子文档、现场、动作按钮、日历状态一屏收进。打开或切换项目时自动弹出（你手动关过，本次会话就不再弹）。

## 功能简介

项目做起来之后，你最常问的三个问题：**现在进展如何、东西都在哪、从哪继续**。驾驶舱一屏回答：

- **头部**——项目名（就地改）、完成总计、归档状态，「甘特图」入口；
- **「今天」卡**——今天班表计数与下一项，点开直达日历；
- **近 14 天进度**——每天完成的走势柱，一眼看出这条线是活着还是凉了；
- **子文档平铺**——项目的整棵树直接铺开，点击跳文档，行内就能加新线；
- **现场卡**——见下；
- **日历同步状态卡**——飞书授权与最近同步的健康度，失效时在这里一键重授权。

「日账」按钮直达当月日志——打点和感想都沉在那。

## 现场保存与恢复

干一个项目常有固定的一组页签：主文档、两篇参考、一篇草稿。**保存现场**把当前页签集拍成快照（记住每篇文档甚至每个块的位置）；**恢复现场**一键回到快照——散乱打开的页签先收掉，原班人马原样回来。

最好用的地方在切换器：**切项目时自动存旧现场、恢复新现场**——你切回来，还是走时的那套页签，不用重新翻。命令面板里也有「保存现场」命令可绑快捷键。

## 动作按钮

项目文档的 `## 动作` 段写清单，驾驶舱自动渲染成按钮：

```markdown
## 动作
- 打开教材 | open /Users/you/book.pdf
- 跑测试 | code npm test
- 继续看视频 | play assets/demo.mp4 --start=00:12:30
```

- 行格式 `- 名称 | 命令`，写得动就行，改完保存驾驶舱即刷；
- 白名单命令（`code` / `open` / `mpv` / `play`）点击直接执行；其余命令第一次点会先弹确认框亮出全文，防误触；
- `play` 在思源内打开视频并从 `--start` 处续播（浏览器版也能用）；看完点按钮区的「记进度」，下次直接从上次的位置接着看；
- 想放只读说明就写不带竖线的行，渲染成浅色提示。

动作段手写、AI 写都行（MCP 有对应工具），它是「项目的快捷方式抽屉」：每个项目放自己的高频动作，互不干扰。

## 收拢已完成

项目推进久了，完成的任务块会铺满文档。头部「收拢已完成」一键把整棵项目树里已完成的任务收进归档区（块 id 不变、双链不断），正文回归清爽，战绩有处安放。
