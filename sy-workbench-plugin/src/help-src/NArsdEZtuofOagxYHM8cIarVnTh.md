MCP 工具族是工作台留给 AI 助手的总接口：ZCode、Cursor 等支持 MCP 的 AI 工具连上后，可以直接查询与操作你的项目、子文档、任务、日历、提醒、作息、弹药库——对话即操作。接入方法在「设置 → 工作台 → AI 接入」。

## 功能简介

工作台分两层：前端薄壳负责看和点；真正的编排大脑在思源内核侧常驻，以 MCP 工具的形式对 AI 开放。这带来一个质变——**你不用学任何界面层级，说人话就行**：「帮我在写作项目建三篇子文档」「这条任务挪到周五」「今晚的交接会开场」。

六个工具，各管一摊：

| 工具 | 管什么 | 典型一句话 |
|---|---|---|
| project | 项目：建、开、进度、归档、动作清单 | 「建一个叫『学日语』的项目」 |
| task | 任务：查、建、勾、排期 | 「把复习卷这一条排到明天上午」 |
| line | 子文档整理：拆、并、归档、找回 | 「这篇写太长了，按二级标题拆成子文档」 |
| calendar | 飞书日历：配置、授权、同步 | 「配置飞书日历提醒」 |
| reminder | 块级提醒：设、查、删 | 「给这段每天早上九点提醒我」 |
| routine | 作息循环：交接会、对账、配额、偏好 | 「今晚交接会」「怕来不及加一条」 |

line 的整理动作全程保留块 id——拆分、合并、归档、找回之后，别处的双链照常工作，这是敢把结构手术交给 AI 的前提。routine 还有一个彩蛋：把思源闪卡的到期卡片分波排进班表（配额制，刷卡仍走官方复习界面），复 deck 不用装新插件。

## 快速上手

1. 打开「设置 → 工作台 → AI 接入」，点**「复制接入提示词」**；
2. 粘贴到你的 AI 工具（ZCode / Trae / CodeBuddy / Qoder 等）发送——它就知道有哪些工具、怎么用；
3. 回到思源干活，对话里直接下指令。

喜欢手动接线的，同一页给了接线地址（`http://127.0.0.1:6806/mcp`，端口以「设置 → 关于」为准；API 令牌即鉴权，无需额外配置）。

**不知道说什么？**「设置 → 用法示例」页备了现成的提示词：建第一个项目、给任务记截止、问项目进展、整理文档结构、换主文档——一键复制，发出去就能看到效果。同一页还有一张文件地图，标明每类数据住在哪篇文档。

## 值得知道的两点

- AI 的每次写操作落的都是你笔记里的块——和你在界面上手点写的是同一批块，没有旁路；
- 内核侧工具在思源启动时常驻，AI 不连接时零打扰——被动接口，不是常驻服务。
