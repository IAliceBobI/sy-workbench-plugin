飞书日历同步的机制与账本：锚点和带截止的任务自动写进飞书日程，到点由飞书服务端推送——思源关着也能到；「设置 → 工作台 → 同步对账」页是只读账本，每条同步了什么、两边是否一致，一目了然。

## 功能简介

**推送无遗漏的底气。** 锚点和带截止的任务自动写进飞书日程，到点由飞书服务端推送：思源没开也响，换设备也到。内核启动时自动跑一轮，之后每小时补一轮；急的话日历页顶栏「同步」立即踢一轮。

**拖动本身就是学习信号。** 同步是双向的：在飞书里拖时间、改标题、删事件，自动回写班表和任务属性——AI 看得懂你在把生活往哪边挪，下次排班更贴你的真实节奏。

**对账页=只读账本。** 「设置 → 同步对账」按四个来源分桶（块提醒 / 任务截止 / 闪卡负担 / 班表），每行显示两边时间与状态：「一致」「上次同步时不一致（drift）」「双变冲突 ×N」——两边都改过才记冲突，冲突次数记数在案。

## 快速上手

1. 先在「设置 → 日历配置」完成飞书授权（没配过的话，那页有四步向导和 AI 代配两条路）；
2. 配好后同步自动跑：内核启动先来一轮，之后每小时补一轮；日历页顶栏「同步」可立即手动踢一轮；
3. 对账页在「设置 → 同步对账」：改完东西想确认同步到位，到对应来源桶里看那行状态是不是「一致」；
4. 闪卡负担是派生数据：只推送到飞书、永不回写思源，在飞书侧删掉它不影响任何数据。

## 常见问题

- **两边时间改得不一样怎么办？** 只在飞书那边改的，自动回写思源；两边都改了的以思源为准，对账页标出漂移（drift）并把冲突（conflict）记数在案。
- **授权过期了？** 约 30 天不用会失效——日历页和驾驶舱出现红态提醒，点「重新授权」即恢复，已同步的数据不受影响。
